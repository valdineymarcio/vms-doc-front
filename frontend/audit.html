O que é a auditoria?

A auditoria registra ações importantes realizadas dentro do sistema.

Esses registros ajudam a identificar quem realizou uma ação, qual documento foi envolvido e quando a operação aconteceu.

Ação

O que aconteceu.

Exemplos:

Documento enviado, documento visualizado, assinatura realizada ou documento devolvido.

Usuário

Quem realizou a ação.

O sistema registra o identificador do usuário responsável pela operação.

Documento

Qual arquivo foi afetado.

Quando a ação envolve um documento, o sistema registra seu identificador.

Exemplos de eventos registrados

Algumas ações que podem aparecer no histórico.

Documento enviado

Um usuário encaminhou um documento para outra pessoa.
Documento visualizado

O destinatário abriu um documento recebido.
Documento assinado

Uma assinatura foi aplicada ao documento.
Importante

Os registros de auditoria servem para rastrear as principais operações do sistema. Evite alterar ou excluir esses registros sem necessidade administrativa.
