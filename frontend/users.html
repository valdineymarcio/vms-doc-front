Gestão de usuários

Apenas administradores podem acessar esta área.

Aqui você pode cadastrar novas contas e definir o nível de acesso de cada usuário.

Administrador

Acesso completo ao sistema.

O perfil ADMIN pode gerenciar documentos, categorias, usuários e consultar os registros de auditoria.

Usuário

Acesso às funções operacionais.

O perfil USER pode cadastrar documentos, receber, visualizar, encaminhar e assinar arquivos.

Novo Usuário

Preencha os dados para criar uma nova conta de acesso.

Informe o nome que será exibido no sistema e nas assinaturas.

Este e-mail será utilizado para entrar no sistema.

O usuário utilizará esta senha no primeiro acesso.
